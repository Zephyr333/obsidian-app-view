# 使用说明

1. 打开“开始体验”。
2. 点击右上角闪电图标“查看速查版”，阅读已选内容。
3. 再次点击图标“返回详细版”，继续在 Live Preview 编辑。
4. 右键顶栏图标或编辑器右键“调整速查版范围”，查看范围边界和背景提示。
5. 选中完整行后点击“加入速查版”，或未选内容时光标直接在标题/段落/列表/代码块/表格上右键免选区收录；光标在已有范围中点击“移除速查版”。
6. 点击“完成调整 (Esc)”，边界回到低干扰隐藏。

也可以在命令面板中搜索“速查版”，或者使用编辑器右键菜单。

标题、段落、完整列表、表格、引用和代码块都可以被选中或免选区收录。不要从代码、表格或嵌套结构中间切开。

速查版是只读视图；所有修改都在详细版完成。手机也需要安装插件，正文由你现有的同步方式同步。
