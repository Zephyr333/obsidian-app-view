# 使用说明

1. 打开“开始体验”。
2. 点击“查看应用版”，阅读已选内容。
3. 点击“返回详细版”，继续在 Live Preview 编辑。
4. 点击“调整应用范围”，查看范围边界和背景提示。
5. 选中完整行后点击“加入选区”；光标放在已有范围中，点击“取消范围”。
6. 点击“完成范围调整”，边界回到低干扰显示。

也可以在命令面板中搜索“应用版”，或者使用编辑器右键菜单。

标题、段落、完整列表、表格、引用和代码块都可以被选中。不要从代码、表格或嵌套结构中间切开。第一版不支持一句话内的部分文字。

应用版是只读视图；所有修改都在详细版完成。手机也需要安装插件，正文由你现有的同步方式同步。
