# 行动版 (Action View)

详细版是唯一正文。选择范围，得到按原文顺序排列、自动更新的纯净只读行动视图。编辑始终留在 Live Preview。

## 安装

当前版本：0.2.0。最低 Obsidian 版本设为 **1.13.7**。

1. 解压 `app-view-0.2.0.zip`，得到 `app-view` 文件夹，里面有 `main.js`、`manifest.json`、`styles.css`。
2. 将文件夹放入目标库的插件目录。默认是 `<你的库>/.obsidian/plugins/app-view/`；自定义过库配置目录时，使用实际配置目录下的 `plugins`。
3. 在 Obsidian 设置 → 第三方插件中启用“行动版”。必要时重新加载 Obsidian。
4. 电脑和手机分别安装并启用。正文通过你已有的方式同步；插件不提供额外同步服务。

不需要 Node.js，不需要其他第三方插件，也不需要维护另一份文件。

## 使用

- **双态切换（对齐原生）**：
  - 点击笔记右上角顶栏图标（`list-checks` / `file-text`）在详细版与行动版之间切换。
  - **普通左键**：当前标签页**原地直接切换**，不产生多余标签页；
  - **中键 或 `Ctrl/Cmd + 左键`**：在**新标签页**中打开；
  - **`Ctrl + Alt + 左键`**：在**相邻分栏**（新标签组）中打开对比。
- **状态记忆**：自动记录每篇笔记最后停留的视图状态。重新打开笔记时，自动以最后状态（详细版或行动版）呈现；若笔记无标记内容，自动降级打开详细版。
- **调整范围入口（零常驻污染）**：
  - **右键编辑区（方案一）**：选中文本右键直接“加入行动版”；光标在范围内右键直接“从行动版移除”；空白处右键可直接“调整行动范围”。
  - **右键顶栏图标（方案三）**：右键点击右上角的行动版图标，弹出菜单项“调整行动范围”与“清除当前笔记所有标记”。
  - **调整过程**：底部浮现轻量悬浮工具条 `[ 行动版调整中 · 已选 N 段 | 加入选区 | 取消范围 | 完成调整 (Esc) ]`，完成或按 `Esc` 键退出后悬浮条收起。
- **纯净阅读体验**：行动版 1:1 对标 Obsidian 原生阅读模式，渲染原生内联文档标题，无任何多余文字按钮或元信息框。
- **平时编辑**：标记行与换行符整行完全折叠，零多余空行，无圆点干扰。启用原子范围保护，光标移动自动跳过，绝不意外展开或误删。
- **同步**：编辑、撤销或收到文件更新后，已打开的行动视图自动刷新。手机显示已经同步到本机的内容。
- **自定义名称**：可在设置中将默认的“行动版”自定义为“精要版”、“实践版”等称谓。



## 范围存储

范围保存在源 Markdown 中，不额外记录字符偏移或块 ID。标记各自独占一行，位于行首：

```markdown
只在详细版显示的解释。

%%app%%
## 应用时要做的事

- 检查条件。
- 执行并记录结果。
%%/app%%

继续详细解释。
```

多个范围按原文顺序显示；不自动补标题、改变标题级别或改写正文。不同范围分开渲染，防止无关列表或表格被意外合并。

## 第一版边界

- 支持标题、段落、多行内容、完整列表、引用／Callout、表格、代码、公式、图片和内部链接。
- 必须选择完整行。表格、嵌套列表、代码块、引用等复杂结构请完整选取；不自动修复被截断的 Markdown，不支持句内几个字的摘取。
- 标记必须位于顶层行首。不支持嵌套或重叠范围。代码块、YAML 属性、缩进代码和普通多行注释中的示例标记不参与收录。
- 未闭合、孤立或嵌套标记会显示具体行号和提示，并清空应用版正文，避免把错误范围当作有效结果。
- 脚注和引用式链接的定义需要放在同一个应用范围内；不会自动收集范围外的定义。普通 `[[笔记]]`、行内链接和图片按源笔记路径解析。
- 应用版只读，任务复选框也不能修改。其他第三方插件的交互代码块、复杂嵌入和主题兼容性未作完整验证。
- 停用插件后，源笔记仍是普通 Markdown；原生阅读视图将边界作为注释隐藏。

## 验证

Windows 的 Obsidian 1.13.7 隔离测试库：

- 10 项范围解析与编辑单元测试。
- 9 项真实应用交互检查：Live Preview 显隐、顺序与过滤、切换返回、添加／取消／撤销／重做、自动更新、跨边界删除恢复、连续修改、文件重命名、手机模拟布局与切换。
- 4 项补充检查：图片／Callout／代码／公式／列表隔离、内部链接跳转、外部文件修改刷新、空状态。
- 390 × 844 手机模拟布局，没有横向溢出，按钮至少 44 CSS 像素高。

**尚未在实际 Android／iOS 手机上验证。** 模拟不能证明真实设备、输入法及同步软件的行为。

`test-vault/` 有可体验的样例，项目内的隔离测试库已安装插件。没有安装到现有个人库，也没有修改其配置。

## 开发

```powershell
npm ci --cache D:\npm-cache
npm test
npm run build
```

产物位于 `dist/app-view/`。运行时代码仅使用 Obsidian、CodeMirror 和浏览器接口，不调用 Node.js、Electron、网络接口或遥测服务。

`scripts/` 中的 CDP 和 QA 脚本仅用于开发，不打入插件包。只允许连接 9237 端口、路径为 `F:\Temp\app-view\test-vault` 的隔离库。测试会修改并恢复样例笔记，不要把路径改成个人库。

源码在首次修改前已建立 Git 基准，功能修改保留在工作区中，便于审核和撤销。
